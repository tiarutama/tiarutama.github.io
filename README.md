## Network Labs

The portfolio contains hands-on networking labs covering:

### OSPF Multi-Router Network
Multi-router topology using OSPF with routing verification, neighbor relationships, route selection, and OSPF cost analysis.

### VLAN & Inter-VLAN Routing
Network segmentation using VLANs, access ports, trunking, and communication between different VLANs.

### BGP Routing Lab
Basic BGP configuration and route advertisement between routers.

### NAT & Network Security
NAT configuration combined with basic network security and traffic filtering concepts.
