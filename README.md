# TIAR. — Network Engineer Portfolio

This package recreates the dark modern technical portfolio direction shown in the reference image.

## Local setup

1. Extract this folder.
2. Open the folder in VS Code.
3. Run `index.html` with Live Server.
4. Replace `your@email.com` in `index.html` with your real contact email.

The profile photo is already placed at:
`assets/images/profile.png`

The green background/glow behind the profile is generated entirely with CSS; the photo itself remains transparent.
